# Блогикум: публикации

Учебный проект на Python 3.14 и Django 5.2.16. Публикации, категории и
местоположения хранятся в SQLite и управляются через русскую админ-панель.

## Запуск

```bash
python3.14 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
cd blogicum
python manage.py migrate
python manage.py loaddata ../db.json
python manage.py createsuperuser
python manage.py runserver
```

Сайт: <http://127.0.0.1:8000/>, админ-панель: <http://127.0.0.1:8000/admin/>.
Учебную папку `static/` с Bootstrap, логотипом и иконками нужно скопировать
из предыдущего проекта в `blogicum/static/`. По чек-листу `static/`,
`static-dev/` и `html/` исключены из Git. База данных и виртуальное окружение
также не входят в репозиторий; база восстанавливается командами выше.

Для сохранения сессий между перезапусками задайте переменную окружения
`DJANGO_SECRET_KEY`. Если она отсутствует, для локальной разработки ключ
генерируется при запуске. Секреты не сохраняются в репозитории.

## Правила публикации

- На главной странице — пять последних доступных публикаций.
- В категории — все доступные публикации этой категории, новые сначала.
- Будущие и скрытые публикации, а также публикации скрытых категорий
  недоступны; запрос их страницы возвращает 404.
- Скрытая локация не скрывает пост: вместо неё выводится «Планета Земля».
- При удалении автора удаляются его посты. При удалении категории или
  локации соответствующая связь становится NULL. Категория обязательна
  при заполнении формы, локация — нет.

## Проверка

Из корня репозитория:

```bash
pytest
flake8 blogicum
python blogicum/manage.py check
python blogicum/manage.py makemigrations --check --dry-run
```

Проверено по чек-листу задания:

- Общая абстрактная модель содержит `is_published` и `created_at`.
- `Category` и `Location` наследуют её `Meta`; `Post` задаёт сортировку
  по убыванию даты публикации в собственном `Meta`.
- Русские названия, подсказки, связи и ограничения полей настроены.
- Фильтрация публикаций вынесена в QuerySet, текущее время вычисляется
  при запросе. Связанные автор, категория и локация загружаются вместе.
- Длины строк и количество постов вынесены в константы.
- Каждое приложение подключено одним `include()` с `namespace`.
- Миграции применены; из `db.json` загружены 173 объекта.
- 84 теста Практикума проходят; flake8 и проверки Django — без ошибок.

Версия Django в исходной заготовке (`5.2.12`) приведена к `5.2.16`,
указанной в уроке и исходном README. Остальные зависимости и тесты
Практикума сохранены без изменений.
